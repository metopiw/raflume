# Güvenlik / Security

## Desteklenen sürüm / Supported version

Yalnızca en güncel Raflume sürümü güvenlik güncellemeleri alır. Only the latest Raflume release receives security updates.

## Açık bildirme / Private reporting

Bir güvenlik açığı bulduysanız lütfen herkese açık Issue açmayın. Deponun **Security** sekmesindeki **Report a vulnerability** seçeneğini kullanın. Etkiyi, yeniden üretme adımlarını ve mümkünse önerilen düzeltmeyi ekleyin.

If you discover a vulnerability, please do not open a public Issue. Use **Report a vulnerability** under the repository's **Security** tab. Include the impact, reproduction steps, and a suggested fix when possible.

Dosya kaybı, yetkisiz dosya erişimi, IPC sınırının aşılması veya güvenli taşıma/geri alma kurallarının ihlali yüksek öncelikli kabul edilir.

Reports involving data loss, unauthorized file access, IPC boundary bypasses, or violations of safe move/undo guarantees are treated as high priority.

## Dağıtım notu / Distribution note

Raflume v1.6.3 Windows paketleri kod imzalama sertifikasıyla imzalanmamıştır. İndirilen dosyaları resmi GitHub Release içindeki SHA-256 değerleriyle doğrulayın.

Raflume v1.6.3 Windows packages are not code-signed. Verify downloads against the SHA-256 values attached to the official GitHub Release.
